# 🤖 Automated Vercel Log Checking

This setup allows me (Auto) to automatically check build logs without you having to copy/paste.

## How It Works

### Option 1: GitHub Actions (Automatic) ✅ RECOMMENDED

Every time you push code, GitHub Actions will:
1. Run the build
2. Extract any errors
3. Create/update `BUILD_STATUS.md` with the latest errors
4. Commit it back to your repo

**I can then read `BUILD_STATUS.md` to see the latest errors!**

**Setup:** Already done! The workflow is at `.github/workflows/check-build.yml`

**To use:**
- Just push your code normally
- Wait ~2 minutes for GitHub Actions to run
- I can read `BUILD_STATUS.md` to see errors
- You can also check the file locally or on GitHub

### Option 2: Local Scripts (Manual)

I've created scripts you can run locally to check Vercel logs:

**PowerShell (Windows):**
```powershell
.\scripts\check-vercel-build.ps1
```

**Bash (Linux/Mac):**
```bash
chmod +x scripts/check-vercel-build.sh
./scripts/check-vercel-build.sh
```

These scripts will:
1. Fetch the latest Vercel deployment logs
2. Extract build errors
3. Save to `BUILD_ERRORS.txt` and `vercel-build-logs.txt`
4. I can then read these files to see errors

**Requirements:**
- Install Vercel CLI: `npm i -g vercel`
- Login: `vercel login`

### Option 3: Direct File Reading

If you run the local scripts, I can read:
- `BUILD_ERRORS.txt` - Just the errors (quick check)
- `vercel-build-logs.txt` - Full build logs
- `BUILD_STATUS.md` - Latest status from GitHub Actions

## Workflow Recommendation

**Best approach:** Use GitHub Actions (automatic) + local scripts (when needed)

1. **Push code** → GitHub Actions runs automatically
2. **I check `BUILD_STATUS.md`** → See latest errors
3. **I fix errors** → Commit fixes
4. **Repeat** → No copy/paste needed!

If GitHub Actions hasn't run yet, you can:
- Run local script: `.\scripts\check-vercel-build.ps1`
- I'll read `BUILD_ERRORS.txt`

## Benefits

✅ **No copy/paste needed** - I can read the files directly  
✅ **Faster feedback** - GitHub Actions runs in ~2 minutes  
✅ **Always up-to-date** - Latest errors are in `BUILD_STATUS.md`  
✅ **Works offline** - Scripts work locally too  

## Files Created

- `.github/workflows/check-build.yml` - GitHub Actions workflow
- `scripts/check-vercel-build.ps1` - PowerShell script

- `BUILD_STATUS.md` - Auto-generated by GitHub Actions (tracked in git)
- `BUILD_ERRORS.txt` - Generated by local scripts (not tracked)
